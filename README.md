# Laboratorio_3-Teoria_de_la_computacion-
## Instalación

Se recomienda utilizar un entorno virtual:

```bash
python -m venv .venv
```

En Windows:

```bash
.venv\Scripts\activate
```

Instalar las dependencias:

```bash
pip install -r requirements.txt
```

## Ejecución

Desde la carpeta del proyecto:

```bash
python main.py
```

El programa leerá todas las líneas de `expresiones.txt`. Después de mostrar el resultado de una expresión, aparecerá su árbol sintáctico. Cierre la ventana para continuar con la siguiente.

Las imágenes generadas quedan en:

```text
arboles/
```
